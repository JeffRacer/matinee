# Matinee

Matinee is a standalone cinematic-authoring addon for Godot 4.7+. Its complete installation boundary is `addons/matinee/`.

The repository contains the addon, a minimal development project, a small original example, focused tests, documentation, and a reproducible ZIP builder. Gameplay, commercial art/audio, story content, and game-specific autoloads are outside this project.

Preserve the existing timeline, selection, editing, and preview architecture. Build toward a polished open-source authoring tool. Runtime integration is explicit; the addon does not install a singleton or assume a host game's managers exist.

Current package version: 0.6.0. This is the Matinee extraction of the existing editor, not a published release.
